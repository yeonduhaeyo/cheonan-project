## 📝 프로젝트 개요
- **목적**: 천안시 내 복지시설(노인복지관, 장애인복지관, 종합복지센터 등)의 **대중교통 접근성 평가 및 개선 방안 도출**  
- **배경**: 교통약자인 노인·장애인 등이 복지시설에 접근하기 어려운 문제 발생  
- **기대효과**: 데이터 기반으로 **취약지역을 식별**하고 **셔틀버스·노선 개선 정책**을 제안하여 교통약자의 이동권 보장

## 🔍 분석 과정
1. **데이터 수집**  
   - 복지시설, 병원, 버스 노선·정류장, 인구 데이터, 행정구역 경계  
2. **데이터 전처리**  
   - 주소 → 위·경도 변환, 정류장-노선 매핑, 좌표계(WGS84/UTM-K) 통일  
3. **EDA(탐색적 분석)**  
   - 시설/인구/노선의 분포 시각화, 취약지역 탐색  
4. **접근성 지표 산출**  
   - 정류장 수, 저상버스 비율, 직선거리, 배차간격 → 가중치 합산 접근성 점수  
5. **불편 지역 분석**  
   - 점수가 낮고 취약계층 인구가 많은 지역 도출  
6. **개선 시뮬레이션**  
   - 노선 조정, 정류장 신설, 셔틀버스 도입 효과 평가  
7. **정책 제안**  
   - 교통약자 맞춤형 대중교통 정책 제시

## 💡 주요 인사이트
- **인사이트 1**: 저상버스 운행이 제한된 지역(예: 좁은 도로, 회전반경 문제)에서 접근성 점수가 낮음  
- **인사이트 2**: 복지시설과 가까워도 정류장 간격이 넓거나 배차가 드문 경우 불편 지역으로 분류됨  
- **인사이트 3**: 노선 공급이 도심에 과밀, 외곽은 부족 → 교통격차 심화  
- **인사이트 4**: 복지시설 유형별 접근성 차이 존재 (노인복지관 > 장애인 재활시설)

## 🏛 정책 제언 / 결론
- **노선 신설**: 저상버스 미운행 지역에 신규 노선 배치  
- **대체 수단 도입**: 대형 저상버스 운행 불가 노선에는 **콜버스·셔틀버스** 도입  
- **기대 효과**: 교통약자의 이동권 보장, 사회적 고립 예방, 복지서비스 접근성 강화

## 🛠 사용 기술
**언어**  
- Python 3.11  

**라이브러리 & 프레임워크**  
- 데이터 처리: pandas, numpy, geopandas, shapely  
- 분석/알고리즘: scikit-learn(DBSCAN), networkx(다익스트라), osmnx  
- 시각화: matplotlib, seaborn, Plotly, PyDeck  
- 웹/대시보드: Shiny for Python, rsconnect-python  

**환경**  
- Jupyter Notebook, VSCode  
- Git/GitHub
